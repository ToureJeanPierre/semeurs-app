# Application « Les Semeurs de la Parole » — dossier de démarrage

Ce dossier contient tout ce que Claude Code doit savoir pour construire l'application de gestion de l'Église évangélique Les Semeurs de la Parole.

## Contenu

| Fichier | Rôle |
| --- | --- |
| `CLAUDE.md` | Qui est Claude Code sur ce projet, la philosophie, la pile technique et les règles de travail. Lu automatiquement. |
| `docs/01-cahier-des-charges.md` | Le besoin complet, module par module, et les décisions validées |
| `docs/02-architecture-et-donnees.md` | Architecture, bibliothèques, modèle de données, sécurité |
| `docs/03-design.md` | Identité visuelle tirée du logo, écrans, animations |
| `docs/04-plan-de-developpement.md` | Les lots, leurs critères de validation, la première demande |
| `docs/05-informations-eglise.md` | Programmes, pasteurs, contacts, données initiales |
| `assets/logo-semeurs.jpeg` | Logo officiel |
| `assets/reference/affiche-evangelisation.pdf` | Affiche de référence |

## Comment lancer

1. Décompresser ce dossier à l'endroit où le projet sera développé.
2. Ouvrir Claude Code dans ce dossier.
3. Copier la première demande qui se trouve à la fin de `docs/04-plan-de-developpement.md`.
4. Valider chaque lot sur le lien Vercel avant de dire à Claude Code de passer au suivant.
